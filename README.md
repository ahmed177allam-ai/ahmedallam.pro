# Ahmed Allam Pro — موقع البورتفوليو

موقع شخصي احترافي لعرض أعمال المونتاج والتصوير، جاهز للرفع على GitHub وربطه بدومين `ahmedallam.pro`.

## هيكل الملفات

```
ahmedallampro/
├── index.html              الصفحة الرئيسية (مش محتاج تلمسها غالبًا)
├── css/style.css           التنسيق والألوان
├── js/
│   ├── site-config.js      ← عدّل هنا: إيميل، واتساب، سوشيال ميديا
│   ├── portfolio-data.js   ← عدّل هنا: أعمالك (فيديوهات وصور) وآراء العملاء
│   └── script.js           الكود اللي بيشغل الموقع (مش محتاج تلمسه)
├── assets/
│   ├── logo.png            اللوجو
│   └── work/                حط هنا أي صور أو فيديوهات ترفعها كملفات مباشرة
└── CNAME                    ملف الدومين المخصص (ahmedallam.pro) — لا تمسحه
```

## 1) عدّل بيانات التواصل (مرة واحدة بس)

افتح `js/site-config.js` وحط بياناتك الحقيقية:
- `email` — إيميلك
- `phoneDisplay` — رقمك بالشكل اللي هيظهر على الموقع
- `whatsappNumber` — نفس الرقم لكن دولي وبدون + أو مسافات (مثال: `201012345678`)
- `social` — حط اللينكات بتاعتك (Instagram, TikTok, YouTube, Behance, Facebook, LinkedIn). أي لينك تسيبه فاضي "" هيختفي تلقائيًا من الموقع.

## 2) ضيف أعمالك (فيديوهات وصور)

كل حاجة بتضيفها بتتحط في `js/portfolio-data.js` داخل مصفوفة `PORTFOLIO_ITEMS`.
في أول الملف شرح كامل بالعربي لكل نوع محتوى:

| النوع | استخدمه لـ | إيه اللي تحطه في `src` |
|---|---|---|
| `youtube` | فيديو من يوتيوب | الكود اللي بعد `v=` في اللينك |
| `vimeo` | فيديو من فيميو | رقم الفيديو من اللينك |
| `video` | ملف فيديو مباشر (mp4) | اللينك أو المسار: `assets/work/name.mp4` |
| `image` | صورة واحدة | المسار: `assets/work/name.jpg` |
| `gallery` | ألبوم صور متعددة لنفس الشغلانة | مصفوفة `images: [...]` بدل `src` |

**علشان ترفع صور أو فيديوهات كملفات مباشرة:** حطها جوه فولدر `assets/work/` وبعدين اكتب اسمها في `src` أو `images` زي المثال في الملف.

بعد ما تضيف أي شغلانة، خليها في القسم الصح عن طريق `category` (الأكواد موجودة فوق في نفس الملف).

## 3) عدّل آراء العملاء (اختياري)

في نفس ملف `js/portfolio-data.js` هتلاقي مصفوفة `TESTIMONIALS` — عدّل النصوص والأسماء أو امسح أي بلوك مش محتاجه.

## 4) رفع الموقع على GitHub Pages

```bash
git init
git add .
git commit -m "الموقع الأول"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

بعدين من إعدادات الريبو على GitHub:
1. روح Settings → Pages
2. من Branch اختار `main` والفولدر `/ (root)`
3. احفظ

## 5) ربط الدومين ahmedallam.pro

- ملف `CNAME` الموجود جوه الريبو خلاص فيه اسم الدومين — سيبه زي ما هو.
- من لوحة تحكم الدومين بتاعتك، ضيف سجلات DNS دي:
  - `A` records لـ `ahmedallam.pro` تشاور على:
    `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
  - أو `CNAME` لـ `www` تشاور على `USERNAME.github.io`
- في GitHub Settings → Pages، حط `ahmedallam.pro` في خانة Custom domain واستنى شوية لحد ما يتفعل الـ HTTPS.

## ملاحظات

- الموقع شغال بالكامل بدون أي سيرفر أو داتا بيز — كله ملفات ثابتة (HTML/CSS/JS).
- أي تعديل في `site-config.js` أو `portfolio-data.js` بيظهر فورًا بعد ما ترفعه على GitHub.
- لو محتاج قسم جديد أو تعديل في التصميم نفسه، ده هيحتاج تعديل في `index.html` و`style.css`.
