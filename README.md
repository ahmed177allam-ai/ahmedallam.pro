# Ahmed Allam Pro — موقع البورتفوليو (نسخة ملف واحد)

عشان نتفادى مشاكل رفع الفولدرات على GitHub، الموقع كله دلوقتي **ملف واحد بس**: `index.html`.
كل حاجة (التصميم، الكود، واللوجو) متضمنة جواه، مفيش فولدرات css أو js أو assets خالص.

## الرفع على GitHub (أول مرة أو استبدال كامل)

1. امسح كل حاجة موجودة في الريبو حاليًا (كل الملفات والفولدرات).
2. ارفع الملفين بس: `index.html` و `CNAME`.
3. من Settings → Pages، تأكد إن Custom domain لسه حاطط `ahmedallam.pro`.

كده خلاص، مفيش فولدرات تتزنق أو ملفات تضيع.

## إزاي تعدل بيانات التواصل بعدين

1. افتح `index.html` من على GitHub، دوس على أيقونة القلم (Edit).
2. دور (Ctrl+F في متصفحك) على كلمة `SITE_CONFIG` — هتلاقي بلوك فيه الإيميل ورقم الواتساب ولينكات السوشيال ميديا، عدّل اللي محتاجه.
3. احفظ (Commit changes).

## إزاي تضيف أعمالك (فيديوهات وصور)

1. في نفس ملف `index.html`، دور على `PORTFOLIO_ITEMS`.
2. هتلاقي شرح كامل بالعربي فوقها لكل نوع محتوى (يوتيوب، فيميو، فيديو مباشر، صورة، ألبوم صور).
3. انسخ أي بلوك موجود واستبدل بياناته ببياناتك.

## إزاي تعدل آراء العملاء

دور في نفس الملف على `TESTIMONIALS` وعدّل الأسماء والنصوص براحتك.

## ملاحظة

الملف كبير شوية (لأن كل حاجة جواه) وده طبيعي وملوش أي تأثير على سرعة الموقع للزوار.
